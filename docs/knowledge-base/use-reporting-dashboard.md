# Review portfolio reporting

**Audience:** Organization administrators and property managers

Use **Reporting** to review inspection volume, issue trends, and Field Operator activity across the properties available to your account.

Reporting has two views:

- **Live Reporting** provides filterable activity and issue analysis across a selected range.
- **Monthly Summaries** stores completed calendar-month portfolio snapshots for management review.

## Open and filter Reporting

1. Open **Reporting** from the Dashboard navigation.
2. Choose a **Date Range** of the last 3, 6, 12, or 18 months.
3. Optionally select one **Property**.
4. Optionally select one **Field Operator**.

Filters apply to the complete reporting result, not only the visible chart or table. Organization administrators can review the organization's reporting scope. Property managers see only properties assigned to them.

## Read the summary

- **Submissions** counts completed inspections matching the filters.
- **Average Submission Time** shows the average local time of day for matching submissions. It is not inspection duration.
- **Inspections With Issues** shows the share of reportable inspections containing at least one checklist response marked as an issue.
- **Issue Types Observed** counts distinct checklist fields that were marked as issues.

**Submission Activity** groups completed inspections by month. **Most Common Issues** ranks issue-marked checklist fields by occurrence. **Field Operator Activity** shows properties serviced, submission count, typical submission time, and the most recently serviced property.

## Understand reporting coverage

Older submissions created before checklist-response tracking can appear in activity totals without contributing to issue-level reporting. When that occurs, Afterlight displays a coverage message showing how many submissions are reportable.

An issue percentage is a workflow indicator, not a safety, compliance, severity, or employee-performance score. Open the underlying property reports before acting on a trend.

## Open detailed reports

Reporting provides aggregate trends. To review the evidence behind a result, return to the Dashboard, open the property's **View Submissions** history, and select **View PDF** for the applicable inspection.

## Review monthly portfolio summaries

Open **Monthly Summaries** to review archived executive portfolio reports. Each property-manager report covers the prior calendar month and only the properties assigned to that manager when the snapshot was prepared. Organization administrators can see summaries prepared for the organization's property managers and may prepare an organization-wide snapshot for their own account.

The monthly report includes:

- submitted inspection and managed-property coverage totals;
- scheduled and completed assignment counts;
- issue-reporting coverage and issue occurrences;
- month-over-month changes;
- property activity and frequently observed issue types; and
- an executive narrative generated from the calculated reporting metrics.

Select **Download PDF** to save the report. In a preview deployment, Afterlight creates the PDF and in-app notification but does not send monthly email. In a live deployment, Afterlight emails the PDF only to the property manager for whom it was prepared. It does not automatically send the report to owners or property recipient lists.

Monthly trends describe Afterlight records at snapshot time. A missing issue in a later month does not prove that an earlier issue was resolved.

## If something goes wrong

- **A property is missing:** Confirm that the property is assigned to the current property manager, or ask an organization administrator to review access.
- **A Field Operator is missing:** Clear the property filter and confirm that the person has a matching submission inside the selected date range.
- **Issue totals are lower than submission totals:** Review the reporting coverage message. Older submissions may not contain structured checklist responses.
- **Average Submission Time looks unexpected:** The value is the average local submission time, not time spent completing an inspection.
- **No data appears:** Increase the date range and clear the property and Field Operator filters.
- **Monthly Summaries says unavailable:** The feature has not been enabled for this deployment or organization.
- **A monthly report is still preparing:** Refresh after a few minutes. The report is generated by a durable background worker and may retry a temporary storage, AI, or email failure.
- **The monthly property count looks wrong:** Ask an organization administrator to verify which properties were assigned to the property manager before preparing another snapshot. Existing monthly reports do not change retroactively.
