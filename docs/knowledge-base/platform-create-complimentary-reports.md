# Create a complimentary prospect report

**Audience:** Afterlight platform administrators

Use **Marketing tools > Complimentary Reports** to create a standalone exterior opportunity report for a prospective customer without creating an organization, property, assignment, or inspection record.

## Create an assessment

1. Open **Complimentary Reports** from Platform Administration.
2. Select **New assessment**.
3. Complete the current prospect checklist. Required fields must be answered before submission.
4. When an opportunity is observed, describe it factually and attach relevant photos when the field allows them.
5. Add optional photos to narrative areas only when they support the observation.
6. Select **Generate assessment PDF** once.

Afterlight creates the PDF and returns to the repository. The assessment is a marketing artifact and is not included in customer reporting, assignments, billing, or Resource Network earnings.

## Use the repository

The **Repository** shows the report name or address, creation date, and scheduled purge date.

- Select **Download PDF** to retrieve a copy before it expires.
- Select **Delete** only when the assessment and PDF should be permanently removed immediately.

Assessments and their PDFs are automatically purged after 30 days. Download any approved business copy before the purge date.

## Maintain the prospect template

1. Select **Template**.
2. Review the template name, report title, and current fields.
3. Update unlocked labels and required settings.
4. Add a field only when it belongs on future complimentary assessments.
5. Remove only unlocked fields that are no longer required.
6. Select **Publish template version**.

Publishing affects future assessments. It does not rewrite PDFs already stored in the repository.

## Protect prospect and photo data

Use customer-approved or otherwise authorized photos. Avoid faces, license plates, access codes, tenant information, and unrelated personal data. Keep descriptions factual and do not present the report as a formal inspection, safety certification, or approved service quote.

## If something goes wrong

- **The PDF is missing:** Refresh the repository. If generation failed, correct the reported field or photo problem and create the assessment again.
- **A report is close to its purge date:** Download the approved copy. The 30-day retention period is not extended from the repository.
- **A field cannot be renamed or removed:** It is protected by the prospect template. Update only unlocked fields.
- **The report needs a price:** Use **Pricing Estimator** separately. Complimentary Reports do not create or approve a quote.
