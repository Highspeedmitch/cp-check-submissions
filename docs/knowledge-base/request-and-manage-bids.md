# Request and manage a property service bid

**Audience:** Commercial property managers and organization administrators

Property managers use **Bid Requests** to request preliminary service pricing for a prospective property. Organization administrators use **Bid Management** to review, decide, archive, and restore those requests.

## Submit a bid request

1. Open **Bid Requests** from the Dashboard navigation.
2. Enter the property's **Gross square footage**.
3. Select the **Property type** and **Service frequency**.
4. Enter the property address and any known issues that affect the request.
5. Attach the lot dimensions with perimeter lines as a PDF, JPG, or PNG.
6. Select **Submit Bid Request** once.

The request appears under **My Requests** and notifies the organization administrator. Submission does not create a managed property, approve a quote, or schedule service.

## Review a request as an administrator

1. Open **Bid Management**.
2. Keep **Active Bids** selected and search by address, requester, or status when needed.
3. Open the lot attachment and review the submitted property information.
4. Review the internal estimated per-visit and monthly pricing when it is available. A manual-review warning means the estimate needs human pricing review.
5. Select **Approve** or **Decline**.

An approved status records the internal decision only. Complete the customer quote, contract, and property-onboarding process separately.

## Archive or restore a request

- Select **Archive** when an active request no longer needs attention. Afterlight asks for confirmation before archiving an undecided request.
- Open **Archived Bids** and select **Restore** when the request should return to the active queue.

Archiving retains the request, attachment reference, requester, pricing estimate, and decision history.

## Protect prospect information

Include only information needed to estimate the service. Do not attach access credentials, alarm codes, tenant records, payment information, or unrelated personal data.

## If something goes wrong

- **The attachment is refused:** Use PDF, JPG, or PNG and confirm that the file is the intended lot document.
- **The estimate requires manual review:** Review the property size, frequency, and known issues before preparing a quote.
- **A request is missing:** Clear the search and check both **Active Bids** and **Archived Bids**.
- **The property should now be onboarded:** Use **Add Properties** after the commercial agreement is approved. A bid decision does not create the property.
